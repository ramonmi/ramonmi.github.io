| 与多 Agent 工作流结合 | 一写一审或独立只读子任务；保持 cwd；必要时隔离 worktree：不默认新增复杂布局，不让多个任务写同一文件 |
| 超时、阻塞与失败处理 | 先读取当前状态；确认是否已提交；避免重复投递：遇审批或提问先核实，不自动替用户确认 |
| 维护与进阶入口 | CLI/服务版本；SSH 与会话概览；配置备份和卸载：远程连接列可选，不自动停止主服务或用户 pane |

### 教程中的操作边界

读者初次启动 Herdr 与 Agent 在已管理 pane 中控制 CLI 是两个阶段。教程中的控制示例先检查 `HERDR_ENV=1`；尚未进入时提示进入 Herdr，不探查或操作别人的焦点会话。命令语法以安装版本的 `herdr --help` 和相应命令组帮助为准，不把无参数运行可能触发创建的命令当作帮助。

基础实践使用普通终端进行布局与只读检查。多 Agent 演示作为读者主动执行的进阶步骤，不授权撰写教程的 Agent 在本机创建 pane、启动其他 Agent 或发消息。切换机器、停止服务和关闭用户会话不属于默认练习。

### 首版示例选择

- 学习结果：能区分操作位置，找到所用工具的准确常用命令和概念解释。
- 先修：对应工具篇。来源：已核验正文及对应官方 CLI 参考。

| 正文 H2 | 正文 H3 与必写内容 |
| --- | --- |
| 术语表 | Harness、Agent、provider、context、session；sandbox、approval、Skill、MCP、hook、plugin：中英文及简短定义 |
| 操作应该在哪里输入 | 系统终端命令；工具内斜杠命令；键盘快捷键；配置文件：采用独立格式和示例 |
| 环境诊断速查 | 当前目录与 HOME；命令位置；Git 状态与 diff：平台不同则分标签，不列高风险清理命令 |
| 九款工具速查 | 每款独立 H3：启动、帮助、版本、登录、退出、恢复、非交互、更新；只收录已确认适用项 |
| 配置与项目指令位置 | 用户级和项目级；相对路径说明：与工具篇一致，不显示作者本机绝对路径 |
| PowerShell 与配套工具速查 | PowerShell 7 版本和命令来源；CC Switch 的 GUI 操作；Herdr 的查看与控制命令；AGENTS.md 检查：分别标明界面、终端和文件位置 |
| 下一步和排障入口 | 每种操作链接正文；失败时链接 P25：速查不承担完整上下文说明 |

- 示例：每款工具采用“目的 / 操作 / 输入位置 / 说明或正文链接”四列表，避免将斜杠命令当作 shell 命令复制。
- 验收：所有操作能追溯到已核验正文，缺少支持的恢复或自动化项目注明不适用，不为填满表格编造命令。

## P27：版本核验与教程维护

- 目标读者：站点维护者和希望确认教程时效性的读者。
- 学习结果：知道教程对应什么版本、验证了什么，以及升级后应该重新检查哪些内容。
- 先修：无。来源：S01–S08 对应发行说明、S17 与当前仓库配置。

| 正文 H2 | 正文 H3 与必写内容 |
| --- | --- |
| 如何读懂版本说明 | 文档核验日期；工具版本；运行验证范围：三个维度分别解释 |
| 当前教程对应版本 | 八工具记录表；平台验证范围：从真实记录生成，未验证不能填“通过” |
| 更新前的检查 | 发行说明；仓库迁移与包名；安装方法：重点检查 Pi、Kimi、OpenCode、DSH 的变化 |
| 升级与迁移顺序 | 备份配置；确认兼容性；升级后验证；处理旧安装：遵循每款官方方法，不保证可以任意降级 |
| 维护一篇教程 | 重查来源；复核命令与截图；更新关联页：工具篇、选择表、速查和排障一起修正 |
| 配套内容维护 | PowerShell 7 安装通道；CC Switch 客户端适配；Herdr CLI 与服务版本；AGENTS.md 加载规则：保留独立版本与证据记录 |
| 验证文档站点 | 现有环境与构建；导航和链接；平台标签与移动显示：区分渲染正确和 Harness 安装正确 |
| 记录限制和更正 | 无法实测的平台；官方未确认项；反馈与更正：给清晰记录格式，不把规划中的功能发布为已支持 |

- 示例：展示一条使用占位字段的维护记录模板，并填充真实存在的核验日期和未运行说明；不可伪造版本号。
- 验收：版本表与来源记录一致，读者能识别教程证据范围；维护步骤覆盖所有关联页面，构建环境限制符合仓库规则。

- P17 客户端适配同时核对 CC Switch 与 Harness 文档；P22–P23 从已核验工具篇汇总扩展和迁移结论。
