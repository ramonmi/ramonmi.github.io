# 版本核验与教程维护

本文面向栏目维护者。安装、模型、权限、CLI 参数和平台支持会变，教程日期不能替代真实的版本核验。

## 版本与来源记录

每次更新工具教程时，记录：页面/工具、核验日期、官方仓库和文档、发行版本或提交、目标平台、实际查看的章节、命令与配置依据、本机是否运行、仍未确认项。官方网页已读不代表安装实测。

## 更新安装步骤

从官方项目入口确认维护状态和发行渠道；检查稳定版/预览版、系统架构、签名或校验、最低依赖。不要将 README 中的开发构建方法当普通用户安装流程。若官方入口失效，先查重定向和官方发布页，再记录未确认点。

## 更新配置与功能

规则文件、会话、审批、扩展和自动化分别核验，不依据同类工具类推。检查示例不会暴露 token、绝对私有路径或本机状态。变更配置示例时给备份和恢复路径。

## 编辑与验收

新增/移动页面时同步更新导航、首页和相对链接。检查全部代码围栏、标题、链接和四空格嵌套。静态审校、Zensical 构建、视觉预览、平台安装测试应分开记录。构建只用项目已验证环境；不得为构建静默创建或升级环境。

## 核验记录模板

```text
工具与页面：
核验日期：
官方项目 / 文档：
目标版本 / 提交：
已读取章节：
平台支持证据：
安装与验证命令：
认证与配置依据：
权限 / 会话 / 扩展 / 非交互能力：
本机运行命令与结果（未运行则写明）：
未确认事项：
```
